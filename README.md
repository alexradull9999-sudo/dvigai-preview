# Двигай — демонстрация сайта

Публичная версия для просмотра дизайна, анимаций, 3D-логотипа и квиза.

В этой копии формы не отправляют и не сохраняют контакты. Квиз рассчитывает рекомендации в браузере; контактные поля показывают демонстрационные значения.

В репозитории только файлы публичной страницы. Сервер, база заявок, секреты и закрытые материалы проекта сюда не включены.

Локальный просмотр: запустите любой статический HTTP-сервер в корне репозитория. Публикация через GitHub Pages из ветки main, папки /.

Лицензии сторонних компонентов находятся в assets/ и vendor/.
